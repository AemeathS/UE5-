01第一章 细节面板概述

1.1 什么是细节面板

细节面板（Details Panel）是 Unreal Editor 中使用频率最高的编辑器面板之一。在关卡视口或世界大纲中选中任意 Actor（角色、物体、灯光、相机等）后，细节面板会立即显示与该选中内容相关的信息、工具和函数，并允许你直接修改它们。

具体来说，细节面板主要提供以下内容：

  • 变换（Transform）编辑框：用于移动、旋转和缩放选中的 Actor。
  • 可编辑属性：显示选中 Actor 及其组件的全部可编辑属性，并按分类组织排列。
  • 快捷编辑功能：根据选中 Actor 的类型提供额外操作，例如将选中 Actor 导出为 FBX、转换为其他兼容类型等。
  • 材质查看与编辑：显示选中 Actor 使用的材质（如有），并可直接打开材质进行编辑。

1.2 如何打开细节面板

在关卡视口或世界大纲中选中任意 Actor 后，细节面板会自动显示。如果面板被意外关闭，可以通过主菜单的 窗口（Window）→ 细节（Details）重新打开；也可以在 窗口 → 加载布局 中选择默认布局来恢复整个编辑器布局。

1.3 面板的整体结构

细节面板从上到下大致分为三个部分：

  • 顶部：Actor 名称编辑框与 Search Details（搜索细节）搜索框；启用收藏功能后，此处还会显示 Favorites 收藏区域。
  • 主体：按分类排列的属性列表，例如 Transform、Static Mesh、Materials、Actor、Rendering、Collision 等。
  • 其他区域：依据选中 Actor 类型动态变化的快捷操作与辅助工具。

02第二章 细节面板通用功能

2.1 Actor 名称（Actor Name）

在细节面板顶部的文本框中直接输入文字，即可为 Actor 设置友好的显示名称。这些名称可以在世界大纲（World Outliner）面板中用于查找、定位和管理相关 Actor，也便于团队协作时快速识别对象。

2.2 搜索过滤（Search Details）

Search Details 搜索框可以根据输入的关键字实时过滤属性，只显示匹配的属性，帮助你在属性较多的 Actor 上快速定位目标。

注意：由于搜索会隐藏不匹配的属性，当你在面板中找不到某个属性时，请先确认搜索框已清空，再检查目标属性是否被过滤掉了。

2.3 收藏功能（Favorites）

收藏功能可以把经常修改的属性标记出来，集中显示在细节面板顶部的 Favorites 区域，实现快速访问。该功能目前标记为实验性功能，部分版本可能行为不一致。

启用方法：主菜单 编辑（Edit）→ 编辑器偏好设置（Editor Preferences）→ 实验性（Experimental）→ 勾选 Enable Details Panel Favorites。修改后可能需要重启编辑器才能生效。

使用方法：启用后，点击属性名右侧的星标图标即可收藏该属性。由于部分属性的定制逻辑较复杂，并非所有属性都支持收藏。

2.4 默认值与重置（Default Values）

当某个属性被修改为偏离默认值的数值时，属性名称旁会显示一个指示器，提示该属性已不再使用默认值。点击该指示器并选择重置，即可把属性恢复为默认值，指示器随之消失。该功能便于在调试时快速还原误改的参数。

2.5 编辑条件（Edit Conditions）

细节面板中的属性可能是启用或禁用状态，只有处于启用状态的属性才能被编辑。默认所有属性都可用，除非它带有编辑条件（Edit Condition）。

带编辑条件的属性是否可编辑取决于另一个变量的值。例如：某个全局开关控制间接光照是否启用，则所有间接光照相关属性都会以该开关为编辑条件——开关关闭时，这些属性被置灰不可编辑。

简单的编辑条件以属性左侧的复选框呈现：勾选表示启用该属性，取消勾选则禁用并置灰。

2.6 EditConst 只读属性

声明为 editconst 的属性在编辑器中不可被修改。这类属性仍会显示其数值，但会被高亮标识，提示你当前值不可编辑。

2.7 属性分类（Categories）

细节面板中的属性按分类组织。部分分类（如 Rendering 渲染、Lighting 光照、Collision 碰撞）由属性在代码中的声明方式决定，用于把相关属性归组；另一部分分类（如 Transform、Static Mesh、Materials、Actor、Code View、Layers）则是引擎内置的自定义组件，用于以更易查找、修改和使用的方式暴露特定属性或功能。

03第三章 Actor 通用属性

3.1 Transform（变换）

Transform 区域显示选中 Actor 的位置（Location）、旋转（Rotation）和缩放（Scale），每个属性都包含 X、Y、Z 三个数值输入框。你可以直接输入精确数值，也可以在输入框内点击并上下拖拽来连续调整。

  • 多选修改：同时选中多个 Actor 且某个轴数值不一致时，对应字段显示 Multiple Values。此时输入数值会把该值应用到所有选中 Actor，可能导致 Actor 相互重叠，请谨慎使用。
  • 重置默认：点击 Reset to Default 按钮，可将位置、旋转、缩放恢复为默认值。
  • 锁定缩放：点击 Lock Scale 按钮后，三个轴的缩放值同步变化，实现等比缩放，防止物体被拉伸变形。
  • 相对/世界坐标：变换默认使用相对坐标（相对于父级组件），点击属性标签旁的下拉箭头可以切换为世界坐标。处理嵌套的父子物体时常用该功能。

3.2 Actor 分类

Actor 分类集中了与 Actor 本身相关的基础属性，常见的有：

  • Tags（标签）：一组用于分组和分类的标签数组（官方 API 描述为 Array of tags that can be used for grouping and categorizing）。常用于蓝图中按标签查找 Actor（例如 Find Actor By Tag）、对物体分类或在关卡逻辑中做标记。
  • Mobility（移动性）：控制 Actor 在游戏过程中能否移动或变化，位于 Transform 坐标下方，详见 3.3 节。
  • Spawn Collision Handling Method（生成碰撞处理方式）：控制 Actor 在与场景其他物体碰撞的位置被生成时的处理方式（例如调整位置、直接失败等）。
  • 初始行为开关：例如 Starts Hidden（初始隐藏）、Starts Enabled（初始启用）、Can Ever Tick（是否每帧更新）等常见开关，用于控制 Actor 的基础行为。
  • Replicates（网络复制）：多人联机项目中控制属性与函数调用是否在网络上同步。
  • Editor Billboard Scale（编辑器图标缩放）：控制编辑器中辅助图标（billboard）的显示大小，不影响运行时效果。

3.3 Mobility（移动性）详解

Mobility 决定 Actor 在运行时能否移动或变化，主要影响静态网格 Actor 和灯光 Actor，是理解光照与性能的关键设置。

表 3-1 Mobility 三种状态对比
状态说明典型应用场景
Static（静态）游戏过程中完全不动、不更新。阴影烘焙进 Lightmass 预计算光照贴图，渲染性能最好；材质仍可做动画。建筑、墙体、地形装饰等固定结构；静态光照场景
Stationary（固定）可以在游戏中改变但不会移动。光照烘焙进光照贴图，同时可为移动物体投射动态阴影；可运行时改变颜色、强度或关闭。会开关或变色的灯、可交互的静态物体；性能与灵活性折中
Movable（可移动）可在游戏过程中移动、缩放、替换等。阴影全动态，不参与预计算光照；支持 Lumen 动态全局光照，但动态阴影开销最大。可移动平台、动态光源、物理物体、会替换的物件

3.4 常见属性分类速览

表 3-2 细节面板常见分类
分类主要包含内容典型用途
Rendering（渲染）可见性、渲染相关属性控制物体在场景中的显示方式
Lighting（光照）光照相关属性控制物体是否参与光照与反射计算

04第四章 网格物体（Mesh）细节面板

4.1 Static Mesh Actor（静态网格）

静态网格 Actor 是最常用的物体类型，用于搭建游戏世界和环境。注意：名称中的 静态 指的是网格几何体在运行时不改变，而非 Actor 不能移动。

  • 放置：从内容浏览器（Content Browser）把网格资产拖入视口即可放置。
  • 材质覆盖：可以在细节面板中单独为每个 Actor 覆盖材质，让同一个网格资产在关卡中拥有不同的外观；也可以直接把材质拖到视口中的 Actor 上完成替换。
  • 运行时移动：默认 Mobility 为 Static，若需在游戏过程中移动、旋转或缩放，必须在细节面板中把 Mobility 改为 Movable。
  • 物理模拟：勾选 Simulate Physics 后，物体受重力影响并参与物理碰撞，例如让球体从高处落下。
  • 碰撞：若网格带有物理体（Physics Bodies），则默认启用碰撞并设置为 Block All（阻挡所有物体）。

4.2 Skeletal Mesh Actor（骨骼网格）

骨骼网格 Actor 用于表现可变形、可动画的网格（通过骨骼和动画序列驱动），典型用于玩家角色、NPC、生物和复杂机械。UE5 第三人称模板中的 Mannequin 即是一个骨骼网格 Actor。

  • 动画：通过动画蓝图（Animation Blueprint）播放和混合多个动画，或直接使用单个动画序列循环播放。
  • 材质覆盖：可单独覆盖材质；材质需在材质编辑器的细节面板中勾选 Used with Skeletal Mesh 选项，才能被骨骼网格使用。
  • 碰撞：骨骼网格无法使用常规的网格碰撞，需要为骨骼网格创建并指定物理资产（Physics Asset）才能与场景正确碰撞（右击网格资产 → 创建 → 物理资产 → 创建并分配）。

4.3 应用场景

静态网格：关卡搭建、环境道具、可拾取物品、动态平台等。骨骼网格：玩家角色、NPC、怪物、可变形机械等需要动画的对象。

05第五章 角色（Character）细节面板

5.1 Character 的组成

Character 是 Pawn 类的扩展，专为竖直方向的人形角色设计，可以行走、奔跑、跳跃、飞行和游泳，并内置了基本的网络与输入模型。它主要由三个组件构成：

表 5-1 Character 的三大组件
组件作用细节面板中常见设置
CapsuleComponent（胶囊体）角色的移动碰撞体。CharacterMovementComponent 假设碰撞体为竖直胶囊。胶囊半径、半高、碰撞预设
SkeletalMeshComponent（骨骼网格）角色的视觉表现与动画驱动。网格资产、动画蓝图、材质覆盖
CharacterMovementComponent（角色移动）控制角色行走、奔跑、跳跃、飞行、游泳等移动行为。移动模式、速度、重力、摩擦等

5.2 CharacterMovementComponent 常用属性

细节面板中的 Character Movement 分类包含大量可调参数，直接影响角色的移动手感。常用属性如下：

表 5-2 角色移动常用属性
属性作用应用场景
Gravity Scale（重力缩放）缩放角色受到的重力低重力关卡、月球跳跃
Max Walk Speed（最大行走速度）角色在陆地上的移动速度角色基础移动速度
Max Fly Speed / Max Swim Speed飞行与游泳速度飞行模式、水下关卡
Jump Z Velocity（跳跃初速）控制跳跃高度调整跳跃手感
Air Control（空中控制）角色在空中的操控灵敏度改善跳跃与落地手感
Ground Friction / Braking Deceleration地面摩擦与制动减速度调整急停、滑行手感
Buoyancy（浮力）角色在水中受到的浮力游泳、水面漂浮
Root Motion（根骨骼运动）由动画驱动角色位移，位移已转换到世界空间翻滚、攀爬等位移型动画

5.3 相机与弹簧臂（第三人称常用）

制作第三人称角色时，通常会在角色上挂载弹簧臂（Spring Arm）与相机（Camera）两个组件：

  • Spring Arm（弹簧臂）：让相机与角色保持一定距离，并处理相机穿墙遮挡问题；可设置目标臂长、是否开启相机碰撞（Camera Collision）、是否启用 Pawn 控制旋转等。
  • Camera（相机）：定义最终视角，在细节面板的 Camera Settings 中设置投影模式、视场角（FOV）等参数（详见第七章）。

5.4 应用场景

玩家角色控制、AI NPC、第一/第三人称视角切换、动画驱动的角色位移（如翻滚、攀爬）、多段跳跃与飞行玩法等。

06第六章 灯光（Light）细节面板

6.1 灯光类型总览

表 6-1 灯光类型与典型场景
灯光类型特点典型应用场景
Directional Light（平行光）模拟无限远的光源，阴影互相平行太阳光、月光等大面积主光源
Point Light（点光源）从单个点向四周均匀发光灯泡、蜡烛、篝火

6.2 点光源属性详解（Light 分类）

以点光源为例，其细节面板属性分为 Light（光照）、Light Profiles（光型）、Lightmass（烘焙）和 Light Function（光函数）四个分类。其中 Light 分类的常用属性如下：

表 6-2 点光源 Light 分类常用属性

Intensity（强度）光源发出的总能量
Light Color（光颜色）光源发出的颜色
Attenuation Radius（衰减半径）界定光源可见影响范围
Source Radius / Source Length（光源半径/长度）光源形状尺寸，影响反射与高光表现
Affects World（影响世界）完全禁用光源；运行时不可修改，运行时关闭请使用 Visibility 属性
Casts Shadows（投射阴影）光源是否投射阴影
Indirect Lighting Intensity（间接光照强度）缩放光源对间接光照的贡献
Use Inverse Squared Falloff（平方反比衰减）使用基于物理的距离衰减，衰减半径仅作截断
Light Falloff Exponent（光照衰减指数）关闭平方反比衰减时控制径向衰减速度
Specular Scale（高光缩放）高光倍率，非 1 值不物理，需谨慎使用
Shadow Bias（阴影偏移）控制阴影的准确程度
Contact Shadow Length（接触阴影长度）屏幕空间接触阴影的追踪长度，0 表示关闭
Cast Translucent Shadows（投射半透明阴影）是否透过半透明物体投射动态阴影
Cast Static / Dynamic Shadows分别控制静态阴影与动态阴影的投射

6.3 Lightmass 与 Light Function 分类

  • Lightmass 分类：影响烘焙光照的参数。例如 Indirect Lighting Saturation（间接光照饱和度，0 表示完全去饱和、1 表示不变）、Shadow Exponent（阴影半影衰减）等。
  • Light Function 分类：把材质作为光函数应用到光源上，实现树影、百叶窗光影等效果。常用属性包括 Light Function Material（光函数材质）、Light Function Scale（光函数缩放）、Light Function Fade Distance（淡出距离）与 Disabled Brightness（禁用时亮度）。
  • Light Profiles 分类：使用 IES 文件描述真实灯具的光型分布，常用属性有 IES Texture（IES 贴图）、Use IES Brightness（是否使用 IES 亮度）与 IES Brightness Scale（亮度缩放）。

6.4 应用场景

日景/夜景布光、室内照明、舞台灯光、窗户漏光、动态光源（火焰、手电）、投影树影等氛围营造。

07第七章 相机（Camera）细节面板

7.1 CameraActor 与 CameraComponent

相机 Actor（CameraActor）主要作为相机组件（Camera Component）的容器，让相机可以直接摆放到关卡中（用于过场动画、监视器等）。相机的大部分行为和属性都配置在相机组件中：在编辑器里选中相机后，通过 细节 → Camera Settings 即可修改。

7.2 Camera Settings（相机设置）

表 7-1 相机常用设置
设置作用应用场景
Projection Mode（投影模式）透视（Perspective）或正交（Orthographic）3D 视角；2D 关卡、平面视图
Field of View（视场角）透视模式下的垂直视场角调整镜头视野大小、冲击感
Ortho Width（正交宽度）正交模式下以世界单位表示的宽度2D 游戏、小地图、俯视视角
Aspect Ratio（宽高比）指定画面宽高比，提供常见设备与显示类型的预设适配不同屏幕/设备
Post Process（后期处理）为相机附加后期效果，并可缩放效果强度色彩校正、景深、风格化画面

7.3 辅助显示

相机组件带有视锥组件（FrustumComponent），用于在编辑器中可视化相机的视场范围。它默认不显示，可在视口中通过 显示（Show）→ 高级（Advanced）→ 相机视锥（Camera Frustums）开启，方便摆放机位和确认取景。

7.4 应用场景

过场动画（Sequencer 机位）、第一/第三人称视角、小地图与监视器画面、建筑可视化漫游、正交平面视图（如 UI 与 2D 关卡）等。

08第八章 碰撞（Collision）细节面板

8.1 Collision Presets（碰撞预设）

碰撞预设是一套常用的碰撞配置组合，位于细节面板的 Collision 分类下。你也可以在项目设置中创建自定义预设。常见预设如下：

8.4 Collision Responses（碰撞响应）

碰撞响应定义本物理体与其他类型物体的交互方式。需要注意：最终结果是双方 Object Type 与响应设置共同决定的结果，修改单侧可能不会生效。

表 8-4 碰撞响应类型
响应结果
Ignore（忽略）无论对方如何设置，都忽略本次交互
Overlap（重叠）对方设为 Overlap 或 Block 时，可产生重叠（Overlap）事件
Block（阻挡）对方设为 Block 时，可产生阻挡（Hit）事件

8.5 Trace Responses（追踪响应）

追踪响应用于射线追踪（例如蓝图节点 Line Trace By Channel）。常见通道包括：Visibility（通用可见性检测）与 Camera（通常用于从相机出发的检测）。

8.6 应用场景

可拾取道具（Overlap + 拾取逻辑）、阻挡玩家通行的墙壁（Block）、触发器区域（OverlapOnlyPawn）、布娃娃死亡动画（Ragdoll）、子弹与武器的射线检测（Trace Responses）等。

09第九章 其他常见 Actor 类型的细节面板

9.1 Volume（体积）类

表 9-1 常用体积 Actor
类型作用应用场景
Trigger Volume（触发器体积）与其他物体交互时触发事件开门、播放过场、区域加载
Blocking Volume（阻挡体积）阻挡玩家通过关卡边界、不可通行区域
Kill Z Volume（击杀体积）进入后立即销毁角色深渊、陷阱区
Pain Causing Volume（伤害体积）对进入者持续造成伤害火焰、毒气区域

9.2 视觉特效类

  • Post Process Volume（后处理体积）：对体积内的物体应用泛光（Bloom）、暗角、全局光照、光追反射等后期效果；效果丰富但开销较大。
  • Reflection Capture（反射捕获）：捕获周围区域的静态图像用于反射，形状分为球体与盒体两种。
  • Planar Reflection（平面反射）：生成 2D 镜面反射，适合镜子、水面等。
  • Decal（贴花）：在网格表面叠加渲染材质，如墙上的污渍、弹孔、涂鸦，用于增加场景细节。
  • 粒子与尼亚加拉（Niagara）：在细节面板中配置发射器、材质与生命周期参数，用于火焰、烟雾、雨雪等效果。

9.3 世界构建类

  • Sky Atmosphere（天空大气）：基于物理的天空与大气渲染，支持日出日落等昼夜变化。
  • Volumetric Cloud（体积云）：基于材质驱动的体积云渲染系统，可灵活定制云的类型。
  • Exponential Height Fog（指数高度雾）：低处密度大、高处密度小的雾效，提供面向主光方向与背向的两个雾颜色。

9.4 音频与文本

  • Ambient Sound（环境音）：在关卡指定位置循环播放声音。
  • Audio Volume（音频体积）：在体积内应用混响、音量、遮挡等音频设置，并定义体积形状。
  • Text Render（文本渲染）：在关卡中直接渲染文本，例如地面上的提示文字。

9.5 应用场景

关卡氛围营造（天空、云、雾）、环境音效与区域混响、场景提示文字、后处理风格化、触发器驱动的关卡机制等。

10第十章 综合应用流程与技巧

10.1 典型关卡搭建流程

综合运用细节面板各分类，一个典型的关卡搭建流程如下：

  1. 从内容浏览器拖入静态网格搭建场景骨架，用 Transform 区域调整位置、旋转与缩放。
  2. 设置关键物体的 Mobility：固定结构为 Static，需要交互或移动的物体为 Movable。
  3. 放置灯光（平行光做日光、点光/聚光做室内照明），用 Light 分类调整强度、颜色与衰减。
  4. 放入角色（Character），配置胶囊体碰撞、Character Movement 移动参数、弹簧臂与相机。
  5. 为需要交互的物体配置碰撞（Block/Overlap）与 Tags 标签。
  6. 添加后处理体积、雾、天空、环境音等完善氛围，最后用相机摆放过场机位。

10.2 高效操作技巧

  • 用 Search Details 搜索框快速定位属性，避免在长列表中翻找。
  • 把频繁修改的属性加入 Favorites，显示在面板顶部。
  • 多选 Actor 批量修改公共属性（注意 Multiple Values 场景下输入会覆盖全部选中项）。
  • 用 Reset to Default 快速还原误改的属性。
  • 用 Lock Scale 保证等比缩放，防止物体变形。
  • 在相对/世界坐标间切换，正确处理父子嵌套物体的变换。
  • 右键属性名可使用复制/粘贴属性值，便于批量传递参数。

10.3 注意事项

  • 运行时需要移动的静态网格必须把 Mobility 改为 Movable，否则无法移动。
  • Movable 光源的动态阴影开销最大，应谨慎使用；Stationary 通常是性能与灵活性的较好折中。
  • 骨骼网格碰撞依赖物理资产，请为角色网格创建并指定 Physics Asset。
  • 碰撞响应由双方共同决定，单侧修改不生效时请检查另一侧的 Object Type 与响应设置。
  • 收藏功能为实验性功能，跨引擎版本行为可能变化，重要工作流不要依赖它。
  • 细节面板中的属性数量随选中组件增多而增加，善用搜索与分类能显著提升效率。
