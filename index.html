一、事件节点

每个事件节点在 Event Graph 中只能用一次；事件没有执行输入引脚，由引擎或系统在特定时机触发。

1.1 生命周期事件

节点触发时机典型场景
Event BeginPlay（游戏开始）游戏开始、Actor 进入世界时触发（游戏开始后才生成的 Actor 会立即触发）初始化变量（血量=100、分数=0）、加载存档、播放开场动画
Event Tick（每帧触发）每帧触发一次，输出 Delta Seconds（距上一帧秒数）逐帧倒计时、摄像机跟随、随时间变化的逻辑
Event EndPlay（结束播放）Actor 离开世界时触发，输出 End Play Reason（结束原因枚举）释放资源、保存数据、清理监听
Event Destroyed（被销毁）Actor 被销毁时触发。⚠️ 官方已标弃用：功能并入 EndPlay死亡后的清理

1.2 碰撞 / 交互事件

节点触发时机典型场景
Event Actor Begin Overlap（开始重叠）与其他 Actor 开始重叠时（要求双方碰撞响应为 Overlap 且 Generate Overlap Events 开启），输出 Other Actor触发器区域、拾取道具、进出门
Event Actor End Overlap（结束重叠）停止重叠时离开危险区、出圈判定
Event Hit（碰撞命中）与实心物体碰撞时（Simulation Generates Hit Events 开启；Sweep 移动也会触发）。输出 My Comp / Other / Other Comp / Hit Location / Hit Normal / Normal Impulse / Hit（HitResult）子弹命中、物体落地、碰撞伤害
OnComponentBeginOverlap / EndOverlap / Hit（组件重叠/碰撞事件）组件级版本，绑定在具体组件上只对某组件（如脚部检测）做碰撞响应
OnActorHit（Actor 碰撞事件）本 Actor 撞到（或被撞到）实心物体时角色撞墙、车辆碰撞
Event Actor Begin / End Cursor Over（光标悬停进出）鼠标悬停到 / 离开 Actor 上时悬停高亮材质
OnClicked（点击事件）组件被鼠标点击时（组件上右键 Add Event → OnClicked 创建）点击物体拾取、点击交互

1.3 伤害事件

节点触发时机典型场景
Event Any Damage（任意伤害）受到任何类型伤害时通用扣血逻辑
Event Point Damage（点伤害）受到点伤害时（弹丸、近战）武器伤害
Event Radial Damage（径向伤害）受到径向伤害时（爆炸）手雷、爆炸范围伤害

伤害事件仅服务器执行（单机时本地即服务器）。

1.4 Event Dispatcher（事件分发器）

  • 作用：让一个蓝图类向 Level Blueprint 或其他蓝图「广播」状态变化；可带参数（相当于事件签名）。
  • 相关节点：Bind Event（绑定）、Unbind Event（解绑）、Assign（赋值绑定）、Call（调用，激活所有已绑定事件）。
  • 关键点：在类蓝图内 Target 自动指向 Self；在 Level Blueprint 中必须连接具体实例引用。
  • 场景：道具拾取广播「拾取」事件 → Level Blueprint 监听后更新任务文本；角色死亡广播 → 全局 UI 显示游戏结束。

1.5 其他事件

节点说明
Event Level Reset（关卡重置）仅在 Level Blueprint 中可用，关卡重载时触发
Event Receive Draw HUD（绘制 HUD）仅 HUD 类蓝图可用，绘制 HUD 内容

二、流程控制节点

节点作用关键引脚典型场景
Branch（分支）最基础的条件分支，按布尔值把执行送往 True / FalseCondition（bool）→ True / FalseIsValid 判断、状态检查后分流
DoOnce（只执行一次）只触发一次，之后不再输出，直到 Reset（官方定义等价于 DoN 且 N=1）Reset（exec）；Completed一扇门只开一次
DoN（执行 N 次）触发 N 次后停止，直到 ResetEnter / n（int）/ Reset；Exit车辆最多启动 20 次
FlipFlop（交替触发）每次调用在 A、B 两输出间交替触发A / B；Is A（bool）开 / 关门动画交替
Gate（执行闸门）开关一扇「执行流闸门」，控制 Enter 能否从 Exit 流出Enter / Open / Close / Toggle / Start Closed；Exit触发器 A 开门、触发器 B 关门
MultiGate（多路分发）把单个执行脉冲路由到多个输出之一；可顺序 / 随机 / 循环Reset / Is Random / Loop / Start Index；Out #轮播动作、随机播对话
Sequence（顺序执行）一个脉冲按顺序触发多个输出（无延迟，几乎同时）Out #（可加）一次事件同时播放音效 + 动画 + 加分
ForLoop（计数循环）在 First~Last 索引间迭代，每轮输出 Index。⚠️ 官方警告：循环在帧间迭代，大循环有性能开销First Index / Last Index；Loop Body / Index / Completed遍历 0~99 生成物品
ForLoopWithBreak（可中断循环）同 ForLoop，额外有 Break 输入可提前跳出 找到目标就停
WhileLoop（条件循环）条件为真时重复执行循环体。⚠️ 必须保证终止条件会更新，否则死循环卡死游戏Condition（bool）；Loop Body / Completed不断吞并直到满足条件
ForEachLoop（遍历循环）遍历数组，每次输出 Array Element 与 Array Index（编辑器 Loops 组）Loop Body / Completed遍历所有敌人
Delay（延迟）延迟指定秒数后从 Completed 输出。⚠️ 倒计时期间再次调用会被忽略Duration（float）；Completed受击后 0.5 秒无敌
RetriggerableDelay（可重置延迟）同 Delay，但倒计时中再次调用会重置计时Duration；Completed连续按键刷新倒计时
DelayUntilNextTick（延迟到下一帧）延迟一个 tick，推到本帧渲染后执行Completed本帧逻辑顺序调整
IsValid（有效判断）判断对象引用是否可用（非空且未 pending kill）Object；Return Value（bool）调用对象函数前判空
Select（按索引取值）按 Index 从多个选项返回一个值（通配类型，变体含 Select Int / Float / String / Class / Object）Option 0 / Option 1 / Index按条件取两值之一
Switch on Int / String / Name / Enum（按类型分支）按输入值把执行送往匹配引脚，无匹配走 Default；Switch on Enum 自动生成枚举选项引脚Selection；各 Case + Default按物品 ID、状态分发逻辑
Map Range Clamped（范围映射（钳制））把 Value 从输入范围线性映射到输出范围，且钳制在输入范围内。示例：0.5 从 0→1 映射到 0→50 得 25Value / In Range A/B / Out Range A/B血量百分比 → 颜色、速度 → FOV
Map Range Unclamped（范围映射（不钳制））映射但不钳制。示例：20 从 10→50 映射到 20→40 得 25同上允许超出边界的映射

UE5 变化：旧版「MapRange」已拆分为 Map Range Clamped（范围映射（钳制）） 和 Map Range Unclamped（范围映射（不钳制）） 两个节点。

类型颜色说明

Byte（字节）藏蓝0~255 整数（unsigned char）

扩展类型：

  • Struct（结构体）：自定义复合数据（把多个字段打包）。场景：道具数据包（名称 + 价格 + 图标）。
  • Enum（枚举）：一组命名常量，配合 Switch on Enum。场景：角色状态（Idle / Walk / Run / Dead）。
  • Class Reference（类引用）：引用蓝图类本身（Spawn Actor from Class 输入、IsA 判断类型），区别于对象引用。场景：指定生成哪种敌人。
  • Interface（接口）：让不同蓝图共享同一组函数契约（IsValidInterface 节点存在）。场景：所有「可交互物」都实现 Interact()。

变量操作技巧：Ctrl + 拖拽生成 Get（读取），Alt + 拖拽生成 Set（写入）。

可见性设置：Public / Instance Editable 允许外部修改；Private 阻止外部蓝图修改；Expose on Spawn 允许生成时传参；Expose to Cinematics 允许被 Sequencer 驱动。

Execution（执行）白色箭头线，表示执行先后顺序——上一节点跑完才跑下一个；Function Call 节点永远只有 1 进 1 出BeginPlay →
Data（数据）彩色线（颜色 = 类型颜色），表示传值，不控制执行顺序；数据引脚按类型着色血量、坐标、引用

关键点：白线决定「先做哪件事」，彩线决定「用什么值做」。彩线连上不会触发节点执行，必须有一条白线流触发节点。未接线时引脚显示为空心圆，接好线后为实心圆。

  • Auto-Casting（自动转换）：把 A 类型引脚拖到兼容的 B 类型引脚时，引擎自动插入转换节点（如 Float→Int、Object→Actor 的 Cast），工具提示会显示兼容类型。
  • Promote to Variable（提升为变量）：右键任意数据引脚 → Promote to Variable，自动创建变量并连线（输出引脚会生成 Set 节点）。
  • Reroute（路由节点）：纯整理用，可当「接线桩」把长线折弯 / 分流，不改变任何数据。
  • Collapse Nodes（折叠图）+ Tunnels（隧道节点）：选中多个节点右键折叠成子图，自动生成 Inputs / Outputs 隧道节点对外通信；折叠图不跨蓝图共享，本质是「把图藏起来」而非复用。
  • 断开连线：Alt + Click 引脚，或右键引脚 → Break Link(s)。
  • 找节点高效姿势：从某引脚拖线到空白处 → 弹出只显示兼容节点的菜单（比右键空白处找全列表快得多）。

18.1 定时器体系（官方 GameplayStatics，正文只覆盖了 Delay）

正文第五章只有 Delay / RetriggerableDelay 两种「延时」，缺定时器句柄（Timer Handle）管理。下列节点来自官方 API 的 Utilities → Time 分类，社区教程（知乎《用法指南》）均有讲解。

节点作用典型场景
Set Timer by Event（按事件设置定时器）设置定时器：到指定秒数后触发指定自定义事件；可循环（Looping）、可立即开始（Initial Start）。返回 Timer Handle 句柄用于后续管理技能冷却倒计时、延时刷新、周期性刷怪
Clear Timer（清除定时器）按句柄清除指定定时器，停止计时与触发冷却结束提前打断、清除过期定时器
Clear and Invalidate Timer（清除并使句柄失效）清除定时器并同时把句柄置空，避免残留句柄误用角色销毁 / 关卡切换时统一清理
Is Timer Active（定时器是否活跃）查询句柄对应的定时器是否仍在运行（返回 bool）防重复启动：同一定时器在跑就不重启
Set Timer by Function Name（按函数名设置定时器）同 Set Timer by Event，但目标是指定函数名（String），适合动态决定调用哪个函数数据驱动的定时任务

注意：Timer Handle 是值类型，把 Set Timer 的返回值存成变量后再传给 Clear Timer，是最标准的「启动—停止」组合链。

节点作用典型场景
